# ESP32-S3 TinyML firmware

The firmware reads an AMG8833 8x8 thermal array, computes the same 76 features
used during Python training, applies the exported `StandardScaler`, and runs a
fully quantized TensorFlow Lite Micro model on the ESP32-S3.

## Setup

1. Install PlatformIO.
2. Copy `.env.example` to `.env` and enter your network and MQTT settings.
3. Connect the AMG8833 over I2C using SDA, SCL, 3.3 V, and GND.
4. Build and upload the `adafruit_feather_esp32s3` environment.

The device listens for `get_one`, `start_continuous`, and `stop` on
`<MQTT_TOPIC>/command`. It publishes the thermal frame, thermistor reading,
prediction, and model confidence to `<MQTT_TOPIC>/readings`.

`include/model_data.h` and `include/model_params.h` are generated by the Python
pipeline in `../ml`. Never commit `.env`; it contains network credentials.

On Windows, use a short checkout path if compilation fails inside the legacy
TensorFlow Lite dependency because of path-length limits.
